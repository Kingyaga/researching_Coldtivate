## Usage Instructions

### System Prerequisites

Your environment must meet the following software requirements before starting:

- **Node.js:** Version 20 or later is required.
- **Yarn:** Version 1.22.19 is the recommended package manager.

### Getting Started Guide

Follow these steps to run the Knowledge Hub locally:

1. **Environment Setup:** Consult our [local development guide](https://docs.coldtivate.org/contributing/local-dev/pwa/#installation) for detailed instructions on configuring your development environment.
2. **Start the Development Server:** Once your environment is configured, initiate the local development server as described in the setup guide. This will allow you to view and test the application in your browser.

### Structure Overview

Knowledge Hub leverages the power of Astro to create a modern and performant web experience. Key architectural pillars include:

* **Internationalization:** Integrated multilingual support for a wider audience.
* **Contextual Adaptation:** Region-specific layout variations for a tailored user experience.
* **PWA Capabilities:** Enabling offline access and enhanced performance.

Detailed insights into the application's technical architecture are available in our [technical documentation](https://docs.coldtivate.org/core-concepts/technical-features/pwa/).
