# Contributing

Thank you for your interest in contributing to our project! This guide provides an overview of the key topics you should review before making a contribution. By following these guidelines, you help maintain the quality, security, and efficiency of our open-source project.

## [Contribution Guidelines](./guidelines.md)
Before making any contributions, please familiarize yourself with our guidelines:

- **[Code of Conduct](/contributing/guidelines/#code-of-conduct)** – Ensure a respectful and inclusive environment for all contributors.
- **[Reporting Issues and Bugs](/contributing/guidelines/#before-submitting-a-bug-report)** – Learn how to properly report bugs, suggest enhancements, and submit feature requests.
- **[Opening Pull Requests](/contributing/guidelines/#your-first-contribution)** – Follow best practices for submitting code changes.
- **[Code Style](/contributing/guidelines/#styleguides)** – Adhere to our formatting and style conventions.
- **[Branching Strategy](./branching-strategy.md)** – Guidelines for creating feature branches, making commits, and merging changes.

## [Local Development Guides](./local-dev/index.md)
To contribute effectively, you need to set up a local development environment:

- **[BASE Backend APIs](/contributing/local-dev/backend)** – Instructions for configuring the backend.
- **[Mobile App](/contributing/local-dev/frontend)** – Steps to set up the frontend.
- **[Knowledge Hub](/contributing/local-dev/pwa)** – Local Progressive Web App setup guide.

## [Testing](./testing.md)
We emphasize end-to-end testing to ensure software reliability:

- **[Testing Approach](/contributing/testing)** – Our strategy focuses on end-to-end tests to validate system functionality.

## [Security Policy](./security-disclosure.md)
Security is a priority. If you discover a vulnerability, follow our responsible disclosure process:

- **[Reporting a Vulnerability](/contributing/security-disclosure)** – Steps to report security concerns confidentially.

---

By following these guidelines, you help us maintain a high-quality and secure project. We appreciate your contributions!
