## Usage Instructions

### System Prerequisites

Your environment must meet the following software requirements before starting:

-   **Python:** Use version 3.9 or any newer release.
-   **pip:** Make sure you're running the most up-to-date version of pip.
-   **MkDocs:** Install version 1.4 or any subsequent update.
-   **Material for MkDocs:** Opt for the newest release of Material for MkDocs.

### Getting Started Guide

To launch the Coldtivate documentation on your local machine, adhere to these instructions:

1.  Install the project's dependencies:

    ```bash
    pipenv install
    ```

2.  Activate the virtual environment
    ```bash
    pipenv shell
    ```

3. Initiate a local server to view the documentation:

    ```bash
    pipenv run mkdocs serve
    ```
